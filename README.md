IDE Chat Agent

This project is an AI-powered chat agent integrated directly into the IDE to assist with code-related tasks.


Setup Instructions
Modify .env file
Install dependencies

Make sure all required packages are listed in requirements.txt, then run:
pip install -r requirements.txt

Run the backend
Navigate to the backend folder and start the API:
python api.py

Using the Agent in the IDE
Press Command + 5 to open the chat panel
Press Command + Shift + P, then open agent

Start interacting with the agent by entering prompts in the chat window
